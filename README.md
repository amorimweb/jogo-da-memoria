# 🎲 Jogo da Memória

Jogo da memória colorido e divertido para crianças, feito em HTML/CSS/JS puro (sem dependências externas).

## Recursos

- 🎨 Ícones em emoji (sem precisar de nenhum arquivo de imagem) organizados em temas: animais, veículos, frutas, espaço e brinquedos
- 👨‍👩‍👧‍👦 Multiplayer local: crie quantos jogadores quiser, cada um com nome e avatar
- 🔀 Banco grande de ícones — cada partida sorteia um conjunto novo e embaralha as posições
- 🔢 Vários tamanhos de tabuleiro (fácil ao desafio)
- 🏆 Placar por jogador com confete na vitória

## Como jogar

Basta abrir o `index.html` em um navegador, ou publicar os arquivos estáticos em qualquer serviço (ex: Vercel).

Nenhuma instalação ou build é necessária — é um site 100% estático.
